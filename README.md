# Bangkok Property Guide AI

The attached file is a part of the code for AI Chatbot Project name "Aurelia" Which will be the chat bot for foreigners who want to invest in real estate in Bangkok Thailand

The attached file will be only reference, do not rely on it completely in order to produce a correct and functional chatbot. Please more consider the supabase that has been successfully connect to you 

The experience I want start with the homepage, where it introduces Aurelia and it's objective and motto, down a little bit is a botton to get to the chatbot. But the homesite are going to have an article like news and chart of recent financial status regarding to relevant to real estate. And some educative information

Then in the chatbot, like other generative AI. The left dashboard is History, function, setting.

And chat must be saved if user go to other page.

And as a reminder. The main duty of the chatbot is to give an advise to foreigners to invest real estate in Thailand. The most important priority is intergity and regulation.
